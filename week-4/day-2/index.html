Framework vs plain CSS

Using Bootstrap classes made it easier to create responsive layouts with flexbox, as the classes like d-flex and flex-column handled the CSS for me. Without Bootstrap, I would have written custom CSS in style.css, such as display: flex; and flex-direction: column;, to achieve the same result.
